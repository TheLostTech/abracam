# Abracam

Il telefono diventa la webcam del computer: inquadri un QR, tocchi Avvia e sei in videochiamata.
Sul telefono non si installa niente. Maschere, ritocchi e filtri in diretta.

**Scarica:** [Abracam per Mac](https://github.com/TheLostTech/abracam/releases/latest/download/Abracam.dmg) ·
Windows in arrivo · Sito: https://abracam.app
